== Runtime, Processes and Resilience

_The infrastructure every long-running service quietly depends on._

Modules: `egse/system.py`, `egse/process.py`, `egse/task.py`, `egse/decorators.py`, `egse/backoff.py` (all in `cgse-common`)

Control servers (Chapter 6) run unattended for extended periods, spawn and monitor subprocesses, schedule recurring work, and need to retry flaky operations without hand-rolled loops scattered everywhere. This chapter covers the shared primitives that make that possible.
