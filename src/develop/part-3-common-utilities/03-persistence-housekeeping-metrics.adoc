== Data, Housekeeping and Metrics

_Where the numbers a device produces actually go._

Modules: `egse/persistence.py`, `egse/hk.py`, `egse/metrics.py`, `egse/plugins/metrics/duckdb.py`, `egse/plugins/metrics/influxdb.py`, `egse/plugins/metrics/questdb.py`, `egse/plugins/metrics/line_protocol.py`, `egse/plugins/metrics/migrate.py` (all in `cgse-common`)

Every control server produces housekeeping and metrics data as a side effect of normal operation. This chapter covers the abstraction that data flows through before it reaches a concrete backend, and the pluggable backend implementations themselves.
